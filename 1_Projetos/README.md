# 1_Projetos · o que está em execução

> O que é: uma pasta por projeto, cada uma com um README.md.
> Estado: modelo.
> Atualizado: 2026-10-28

Projeto tem data para acabar. Cada um ganha uma pasta com nome curto (`campanha-vida-dezembro/`) e um `README.md` copiado de `_modelo-projeto.md`.

Quando terminar, a pasta inteira vai para `4_Arquivo/AAAA/`, com um `FECHAMENTO.md` dizendo o que deu certo, o que não deu e o que você faria diferente.
