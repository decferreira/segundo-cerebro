# Anotar

**Quando:** o dono joga algo solto ("anota isso", "guarda para depois") · **Saída:** um arquivo novo em `0_Entrada/`

## Faz

1. Crie `0_Entrada/AAAA-MM-DD-<assunto-curto>.md` com as três linhas de cabeçalho e o conteúdo com as palavras dele.
2. Se for claramente de um lugar só (uma pessoa que já tem ficha, um projeto que já existe), escreva lá direto e diga onde gravou.
3. Commit e push.
4. Responda em uma linha: "Anotado em <arquivo>."

## Regras

- Não organize, não resuma demais, não proponha plano. É captura.
- Se for ideia nova no meio de outra tarefa, guarde e volte para a tarefa. A ideia é decidida na sexta.
- Se o conteúdo tiver CPF, apólice ou dado de saúde de cliente, guarde só o que não é sensível e avise.
